# Barber House

## Sobre o projeto

O Barber House surgiu a partir de um problema observado em uma barbearia real: os atendimentos e planos eram registrados manualmente em um caderno, enquanto os agendamentos eram realizados por outro aplicativo.

A proposta do projeto é reunir essas funções em um único sistema web. Além do agendamento, o planejamento inclui o registro dos atendimentos, controle dos planos mensais, ranking de produtividade e cálculo da distribuição dos valores entre os barbeiros.

## Versão atual

A primeira versão permite conhecer os planos disponíveis, realizar agendamentos avulsos ou pelo plano, impedir horários duplicados e consultar os atendimentos no painel da barbearia utilizando filtros por data e profissional.

## Funcionalidades

- Visualização dos planos mensais.
- Agendamento de atendimentos avulsos ou pelo plano.
- Seleção de serviço, barbeiro, data e horário.
- Bloqueio de horários duplicados para o mesmo profissional.
- Armazenamento dos agendamentos no navegador.
- Painel para consulta dos atendimentos.
- Filtros por data e barbeiro.
- Layout responsivo para computador e celular.

## Tecnologias utilizadas

- HTML: estrutura e conteúdo das páginas.
- CSS: estilização, organização dos elementos e responsividade.
- JavaScript: manipulação dos dados, eventos, filtros e criação dinâmica dos agendamentos.
- localStorage: armazenamento local dos dados no navegador.
